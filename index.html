Formulas Power BI / DAX
Agregacion
SUM
Basica
SUM(Tabla[Columna])
Suma todos los valores de una columna
SUMX
Iteradora
SUMX(Tabla, Tabla[Precio] * Tabla[Cantidad])
Suma el resultado de una expresion fila por fila
CALCULATE
Clave
CALCULATE(SUM(Ventas[Monto]), Ventas[Region] = "Norte")
Modifica el contexto de filtro para evaluar una expresion
AVERAGEX
Iteradora
AVERAGEX(Clientes, [Total Ventas])
Promedio del resultado de una expresion por cada fila
Tiempo
TOTALYTD
Tiempo
TOTALYTD(SUM(Ventas[Monto]), Fechas[Fecha])
Total acumulado del año hasta la fecha actual
SAMEPERIODLASTYEAR
Tiempo
CALCULATE([Total Ventas], SAMEPERIODLASTYEAR(Fechas[Fecha]))
Mismo periodo del año anterior
DATEADD
Tiempo
CALCULATE([Total], DATEADD(Fechas[Fecha], -1, MONTH))
Desplaza un periodo: -1 mes, -1 año, etc.
IF
Logica
IF([Total Ventas] > 50000, "Alto", "Bajo")
Condicion: si se cumple devuelve un valor, si no otro
DIVIDE
Logica
DIVIDE([Ventas], [Meta], 0)
Division segura, evita el error de dividir entre 0
